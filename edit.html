Edit your portfolio

Private editing page. Type your text, add your photos, then press Save. Only someone with your GitHub key can change the site.

1. Connect

First time? How to get your GitHub key (2 minutes)
  1. Sign in to GitHub, click your picture at the top right, then Settings.
  2. At the bottom of the left menu click Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Click Generate new token. Name it portfolio. Set Expiration to 90 days or longer.
  4. Under Repository access choose Only select repositories and pick your .github.io repository.
  5. Under Permissions → Repository permissions, find Contents and set it to Read and write.
  6. Click Generate token, copy the long text that starts with github_pat_ and paste it below.

This key can only change this one website. Never share it with anyone.
